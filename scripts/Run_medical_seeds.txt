البذرة الكاملة محفوظة مسبقاً. لاسترجاعها في مساحة العمل المحلية شغّل من جذر المشروع:

npm run seed:medical:restore

هذا يعيد 248 موظفاً و225 خدمة و10 عملاء والجداول والإجازات. بعدما ينتهي حدّث صفحة المتصفح.

إذا أردت توليد نفس الطاقم من جديد ثم حفظه كنسخة احتياطية:


npm run seed:medical


بعد update:all أو refresh تُسترجع هذه البذرة تلقائياً.
