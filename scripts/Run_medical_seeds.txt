البذرة الكاملة للمستشفى محفوظة في:
  data/seeds/medical-demo-ops.json

── حفظ باك أب من أكبر بيانات شغّالة + إثراء مواعيد للاختبار ──
  npm run hospital:save-full
  (السكربت: scripts/save-full-hospital-backup.js)

── فرد / استرجاع البذرة المحفوظة ──
  npm run hospital:restore-full
  أو: npm run restore:full-hospital

بعدما ينتهي حدّث صفحة المتصفح (F5).

── أوامر قديمة (ما زالت تعمل) ──
  npm run seed:medical:restore
  npm run seed:medical          (توليد طاقم جديد ثم حفظ)

بعد update:all أو refresh تُسترجع هذه البذرة تلقائياً عند مسار الاختبارات الطبية.
