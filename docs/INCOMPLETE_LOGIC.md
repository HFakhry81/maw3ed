# منطق غير مكتمل — موعد

قائمة بنود يجب إغلاقها قبل الإطلاق. يُذكَّر الفريق بها باستمرار.

## تسعير الخدمة

1. **نطاق (range)** — حقول «يبدأ من» / «ينتهي عند» محفوظة في الخدمة، لكن ربط السعر الفعلي ضمن النطاق عند طلب/تأكيد الحجز **غير مكتمل**.
2. **عند الطلب (on_request)** — إخفاء السعر في العرض العام، وتحديد السعر عند طلب الخدمة **غير مكتمل**.

## ملاحظات

- حتى يُغلق البندان أعلاه: الواجهة تحفظ النوع والحقول فقط، والحجز العام يعرض تلميحاً دون فرض سعر نهائي للنطاق/عند الطلب.
