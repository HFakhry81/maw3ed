# الملكية والعلامة التجارية

- اسم المنتج: **موعد / Maw3ed** (AR: موعد · EN: Maw3ed)
- المالك والمطور: **UpNexa-eg.com**
- حقوق البرمجيات والهوية البصرية والأيقونة والمحتوى محفوظة لـ UpNexa-eg.com.
- أي نشر أو إعادة استخدام تجاري أو إعادة توزيع يحتاج إلى موافقة كتابية من مالك المنتج.
- مزود البريد المستخدم للتحقق: Gmail عبر تكامل Replit وصلاحيات OAuth، مع إبقاء بيانات الدخول خارج المستودع.
- **SetTime** ومواد `attached_assets/` المرتبطة به مرجع تنافسي/تجربة مستخدم فقط — ليست علامة المنتج ولا ملكية للمنصة.
