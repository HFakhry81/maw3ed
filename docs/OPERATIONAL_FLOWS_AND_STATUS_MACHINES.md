# تدفقات التشغيل وآلات الحالات — توصيف منتج موعد

**الحقيقة المنتج:** موعد منصة **حجز وتشغيل متعددة الأغراض**، وليست منصة مستشفى/عيادة فقط. العيادة قالب نشاط واحد ضمن قوالب أخرى (تعليم، صالون، تجميل، ساونا، بلياردو، ملاعب، ألعاب، رياضة، خدمات عامة…).

هذا ملف **توصيف مستهدف** للدورة التشغيلية والحالات. أي تنفيذ لاحق يُقاس عليه؛ لا يُعد وجود هذا الملف دليلاً على اكتمال الإنتاج.

## نماذج الحجز الموحّدة (BookingType)

| BookingType | occupancy_mode المستهدف | أمثلة الأنشطة | الدورة |
| --- | --- | --- | --- |
| `APPOINTMENT` | `exclusive` | مستشفيات، عيادات، صالونات، تجميل، ساونا | خدمة ← حجز مفرد ← فتح جلسة |
| `RESOURCE_RENTAL` | `rental` | بلياردو، ملاعب، صالات ألعاب | مورد/طاولة ← فتح جلسة ← إغلاق وتحصيل |
| `BATCH_SCHEDULE` | `session_capacity` | مراكز تعليمية، دروس، حصص جماعية | مادة/مرحلة ← حصة/مجموعة ← حضور |

لا يُستنتج نمط الحجز من اسم النشاط وحده؛ تُعلن السياسة على الخدمة. القالب يضع الافتراضي فقط.

---

## 1) Medical Flow — المستشفيات والعيادات (وامتداد APPOINTMENT)

**الدورة:** خدمة ← حجز مفرد ← فتح جلسة (Session/Visit)

### حالات الخدمة
| الحالة | المعنى |
| --- | --- |
| Active | الخدمة متاح الحجز عليها |
| Inactive | الخدمة متوقفة مؤقتاً عن الحجز |

### حالات الحجز المفرد
| الحالة | المعنى |
| --- | --- |
| Confirmed | تم حجز الموعد وتأكيده |
| Pending | حجز مبدئي يتطلب تأكيداً إدارياً أو دفعاً |
| Cancelled | أُلغي من العميل أو المنشأة |
| Rescheduled | نُقل لوقت آخر |
| No-Show | انقضى الموعد دون حضور |

### حالات الجلسة / الكشف
| الحالة | المعنى |
| --- | --- |
| Checked-In | وصل للاستقبال/الانتظار |
| In-Progress | جاري الكشف/التنفيذ |
| Completed | أُغلقت الجلسة |
| Paused/On-Hold | مفتوحة وتحتاج إجراء قبل الإغلاق (تحاليل/أشعة…) |

## 2) Educational Flow — المراكز التعليمية والدروس

**الدورة:** مادة / مرحلة ← حصة / مجموعة (Batch) ← حضور طالب (Check-in)

### حالات الحصة/المجموعة
| الحالة | المعنى |
| --- | --- |
| Open | مقاعد متوفرة |
| Full | وصلت للسعة القصوى |
| Cancelled | أُلغيت مع تنبيه الطلاب |

### حالات حضور الطالب
| الحالة | المعنى |
| --- | --- |
| Attended/Checked-In | مسح QR عند الدخول |
| Absent | لم يحضر (إشارة لولي الأمر عند التفعيل) |
| Excused | غياب بعذر مقبول |

---

## 3) System & Staff Binding — الربط الإداري

### ربط الموظف بالفرع (Staff–Branch / workspace)
| الحالة | المعنى |
| --- | --- |
| Active | صلاحيات إدارة الفرع/المساحة فعّالة |
| Suspended | تعليق الصلاحيات في هذا الفرع مع إبقائها في فروع أخرى |

---

## 4) صالونات الحلاقة والتجميل والساونا — نمط موعد / مقدم خدمة

**الدورة:** خدمة (أو باقة) ← حجز موعد (أو كرسي/خبير) ← بدء جلسة / تنفيذ

يندرج تحت **APPOINTMENT** مع حالات إضافية شائعة:
- الحجز: Confirmed · Waitlisted · Pending · Cancelled · Rescheduled · No-Show
- الجلسة: Arrived/Checked-In · In-Service · Completed

خدمة Active/Inactive كما في القسم 1.

---

## 5) البلياردو والمعدات والملاعب — نمط مورد / وقت حقيقي

**الدورة:** طاولة / جهاز (Resource) ← فتح طاولة (Open Session / Tab) ← إغلاق وتحصيل

يندرج تحت **RESOURCE_RENTAL**. غالباً جلسة حية أو حجز مدة، وليس «موعد عيادة» فقط.

### حالات الطاولة/المورد
| الحالة | المعنى |
| --- | --- |
| Available | خالية وجاهزة |
| Occupied / In-Use | جيم/استخدام جارٍ |
| Reserved | مخصصة لعميل قادم |
| Under Maintenance | صيانة |

### حالات جلسة اللعب/الاستخدام
| الحالة | المعنى |
| --- | --- |
| Open Session / Active | عداد شغال |
| Fixed-Time Session | مدة محجوزة مسبقاً |
| Paused | إيقاف مؤقت للعداد |
| Closed / Pending Payment | انتهى الاستخدام وجاري الحساب |
| Settled / Completed | دُفعت الفاتورة وفُرغ المورد |

## دورة التشغيل الكاملة المطلوبة للمنصة (إنتاج)

لكل نشاط قائم على تقديم خدمة:

1. إنشاء مساحة عمل واختيار قالب نشاط
2. إنشاء خدمة بما يلزمها من موظفين/مقدمين وموارد
3. ساعات العمل وسياسة الحجز
4. الحجز (عام أو مكتب) بدون تضارب / مع سعة مقاعد حسب النموذج
5. QR / رمز حضور
6. جلسات الحضور أو التنفيذ حسب BookingType
7. الفاتورة النهائية والتحصيل للعميل
8. ربط الموظف بالفرع: Active / Suspended

## مفاتيح تخزين مقترحة (للتوحيد في الـ Backend)

- خدمة: `active` | `inactive`
- حجز APPOINTMENT: `pending` | `confirmed` | `waitlisted` | `rescheduled` | `cancelled` | `no_show`
- جلسة APPOINTMENT: `checked_in` | `in_progress` | `paused` | `completed`
- مورد: `available` | `occupied` | `reserved` | `under_maintenance`
- جلسة إيجار: `open` | `fixed_time` | `paused` | `closed_pending_payment` | `settled` | `cancelled`
- حصة: `open` | `full` | `cancelled`
- حضور: `attended` | `absent` | `excused`
- ربط موظف: `active` | `suspended`
